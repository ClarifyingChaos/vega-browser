# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private reporting: **[Report a vulnerability](https://github.com/ClarifyingChaos/vega-browser/security/advisories/new)**.

Include what you found, the steps to reproduce it, and the Vega version (Vega › About Vega). You will get a reply as soon as possible, and a fix is released before the problem is described in public.

## Supported versions

Only the latest release is supported. Vega updates itself, and each release lists a privacy and security review in [VEGA_CHANGELOG.md](VEGA_CHANGELOG.md).

## What Vega relies on

Vega draws web pages with Apple's WebKit, so fixes for the engine itself come with macOS updates. Keep macOS up to date.

Problems in Apple's WebKit should be reported to Apple. Problems in the upstream project Vega is built on may also be reported to [its repository](https://github.com/nook-browser/Nook).
