Questions.

Is Vega free?

Yes. Vega is free and open source. The code is on GitHub for anyone to read and build.

Which Macs does it run on?

Any Mac with macOS 15.5 or later.

What is it built on?

Vega uses Apple's WebKit, the engine behind Safari, so pages are fast and battery-friendly. It began as a fork of the open-source Nook browser.

Why sign in with Google?

Only to sync between your own Macs. The sign-in tells the Vega Sync server which files are yours. Vega can reach only its own hidden folder in your Google Drive, and nothing else in your account.

Do my Chrome extensions work?

Many do. Vega runs Safari-style web extensions and supports a growing number of Chrome Web Store extensions.

How do updates work?

Vega checks for new versions and updates itself. You can also check from Settings › Updates.
